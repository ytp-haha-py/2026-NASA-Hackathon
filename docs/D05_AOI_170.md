# D05 AOI/time illumination and ionizing-radiation evidence (Issue #170)

Status: **bounded, model-derived illumination geometry plus an explicit
missing-value record for ionizing radiation.** This is not observed irradiance, not a
shadow-fraction product, and not a radiation dose. Two AOIs are covered — one Moon and
one Mars — over an explicit 24 h UTC window.

## 3) Shadow / horizon support — what is and is not available

Available: a **geometric flat-ellipsoid horizon** per AOI — contiguous above/below
runs at sampled instants and zero crossings refined by bisection with the same model.
See `horizon.json`.

Not available: a terrain horizon, ridge shadow mask or horizon visibility interval.
Reason: Raw DEM rasters are not committed and no bounded DEM ingest is part of this scope, so no terrain horizon, ridge shadow mask or horizon visibility interval is computed. Only the geometric flat-ellipsoid horizon (Sun above/below the local tangent plane) is reported.

The consequence is explicit: a near-polar site that the flat model places just below
the tangent plane is **not** thereby proven to be in permanent darkness; local relief
can illuminate it. For `moon-shackleton-rim-site04-roi1` the highest sampled elevation is
-0.283213 deg, so the unmodeled margin is only about
0.283 deg. The pilot reports the geometric result only and makes no shadow
claim.

- Requested window: `2026-03-01T00:00:00Z` .. `2026-03-02T00:00:00Z`; audited archive time overlap: `true`.
- Values produced: `0`.
- Blocker: LRO-L-CRAT-3-CDR-CALIBRATED-V1.0: CRaTER measures energy deposition in an orbital detector stack, not absorbed dose at a lunar surface AOI.
- Blocker: LRO-L-CRAT-3-CDR-CALIBRATED-V1.0: No surface dose transport model, detector-to-surface mapping or shielding/geometry model is selected or applied in this scope.
- Blocker: LRO-L-CRAT-3-CDR-CALIBRATED-V1.0: The archived 'accumulated radiation dosage' housekeeping is instrument dosage, not a surface absorbed or equivalent dose.

- Blocker: LRO-L-CRAT-2-EDR-RAWDATA-V1.0: Reduction requires the CRaTER calibration and a surface transport model that are outside this bounded audit.
- Blocker: LRO-L-CRAT-3/4-DDR-PROCESSED-V1.0: Level-2 products are detector energy deposition and estimated LET, not surface absorbed or equivalent dose.
- Blocker: LRO-L-CRAT-3/4-DDR-PROCESSED-V1.0: No LET-to-dose transport, geometry or shielding model is applied here.

### `mars-jezero-ctx-window-01`

- Typed state: `no_coverage`; coverage decision: `no_coverage`; AOI attribution: `different_site`.
- Requested window: `2026-03-01T00:00:00Z` .. `2026-03-02T00:00:00Z`; audited archive time overlap: `true`.
- Values produced: `0`.
- Blocker: MSL-M-RAD-3-RDR-V1.0: The audited in-situ dose record is measured at Gale Crater, about 3,752 km from the Jezero AOI (great-circle, spherical R=3389.5 km); it is not an AOI observation.
- Blocker: MSL-M-RAD-3-RDR-V1.0: RAD RDR labels in the audited Sol carry placeholder ROVER_LAT/LON=0.000, so the archived record does not provide a usable per-record position for AOI attribution.
- Blocker: MSL-M-RAD-3-RDR-V1.0: No spatial mapping from the Gale record to the Jezero AOI is documented or applied; no proxy is substituted.
- Blocker: MSL-M-RAD-2-EDR-V1.0: EDR is raw event/telemetry data at Gale Crater, not a calibrated absorbed-dose value and not an observation at the Jezero AOI.

Typed representation: `feature_id=ionizing_dose_gy`, `value=null`,
`state=no_coverage`, `unit=Gy`, `score_role=evidence_only`. The typed-v2 state
vocabulary has no `unsupported` value, so semantically unsupported cases are recorded

`radiation_sources.json`.

Forbidden and not applied: flux-to-dose, Gy-to-Sv, orbital energy deposition to
surface dose, and in-situ dose at one site to a different AOI. No value is zero-filled.

## 7) Limits and blockers

- Model-derived geometry only; not observed irradiance, radiance or power.
- Flat biaxial-ellipsoid tangent plane; no terrain horizon, shadow mask, observer
  height, atmosphere, cloud or dust model.
- The AOI is placed on the reference ellipsoid; source DEM elevations are not added.
- Point AOI centres, not a spatial average over the existing 1.98 km DEM windows.
- Source projected-CRS to body-fixed-frame registration remains a documented
  assumption (lunar prime meridian; Mars 2000/IAU_MARS), not an independent geodetic
  validation.
- No AOI-attributable ionizing-radiation product exists in this bounded scope; the
  audited alternatives are orbital detector data (Moon) or in-situ data at another
  landing site (Mars).
- No global or exhaustive coverage; no cross-body D05 score.

## 8) Exact commands

```bash
uv sync --extra spice
uv run --extra spice python scripts/build_d05_aoi_illumination.py --download
uv run --extra spice python scripts/build_d05_aoi_illumination.py
uv run --extra spice python scripts/build_d05_aoi_illumination.py --probe-radiation --download
uv run --extra spice pytest pipelines/tests/test_d05_aoi_illumination.py -q
uv run ruff check .
uv run ruff format --check .
```

The first builder invocation fetches only the five pinned kernels when they are
missing. `--probe-radiation` performs bounded PDS metadata requests (catalog and one
label range probe, capped at 64 KiB each). Without it the committed audit evidence is
reused and no network call is made.
