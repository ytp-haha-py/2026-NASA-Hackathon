# D02 AOI evidence for Moon and Mars (Issue #170 Goal E)

Status: **bounded, evidence-only, no mineral detection and no abundance**. This
report documents official footprint discovery and D02 product provenance for one
real Moon AOI and two explicitly marked Mars test AOIs. It does not rewrite the
existing D02 typed bundles, does not add a similarity score, and does not present
a subset as a global survey.

- Evidence directory: `pipelines/d02_d04_aoi/geology/`
- Builder: `pipelines/d02_d04_aoi/geology/build.py`
- Tests: `pipelines/d02_d04_aoi/tests/test_d02_aoi_geology.py`
- Official service: NASA PDS Geosciences **ODE REST V2.1.5** (`live2`)
- Discovery time: 2026-11-15T14:16:44Z–14:16:51Z
- Download class: JSON metadata and small PDS labels only; **0 raster bytes**

PR #161 (`feat/135-139-bounded-ingest-expansion`) contributes bounded **Earth**
Macrostrat map-unit evidence and no Moon/Mars D02 rows. Its Earth rows are not

## 5. State semantics

| State | Meaning in this evidence |
|---|---|
| `unknown` | Official metadata exist and the footprint may cover the AOI, but no validated spectral retrieval, mineral identification or valid-data mask was read. `value`, `unit` and `valid_fraction` are `null`. Footprint coverage alone cannot promote this state. |
| `no_coverage` | The official query returned no product, or the AOI does not intersect the product footprint. Fractions, areas and values are `null`. This is not a numeric zero and not evidence of absence. |
| `detected` | Never emitted here. |
| `not_detected_under_valid_observation` | Never emitted here because no valid observation was read. |
| `not_applicable` | Not used. |

`coverage.state` is separate from the mineral `state`: `complete`, `partial` and
`no_coverage` describe spatial overlap only. A complete footprint is still an
`unknown` mineral state.

## 7. Per-source status and blockers

| Source | Status | Evidence | Blocker / limitation |
|---|---|---|---|
| NASA PDS Geosciences ODE REST | all 5 queries `Success` | exact URLs, counts, response hashes | Metadata service only; footprint is not a valid-data mask. |
| Chandrayaan-1 M3 L2 REFIMG | product metadata + PDS3 labels verified for 4 records | labels in `queries/labels/`; 3 complete + 1 partial footprint | No map scale/pixel size in label; M3 registration/geolocation and polar illumination unvalidated; no spectral value read → `unknown`. |
| LRO LROC WAC TiO2 | AOI query count 0; family 16 tiles, 70 S–70 N | family query summary + sample PDS4 label | No polar tile exists in this product family; explicit `no_coverage`, not zero abundance. |
| MRO CRISM MTRDR | product metadata + PDS4 labels verified for 5 products | labels, orbit, pixel scale, ODE footprint | No spectral cube, summary parameter or DP mask read; thresholds unvalidated; two test AOIs only → `unknown`/`no_coverage`. |
| USGS Moon/Mars geologic maps | reused from existing typed bundle | `pipelines/geology/typed/`; each AOI summary has a read-only `existing_geology_evidence` link | Not re-queried or rewritten in this slice; no new map-unit evidence claimed. |
| Existing D02 area-fraction and mineral pilots | referenced, not modified | `pipelines/geology/area-fraction/`, `pipelines/pilots/d02_spectral_detection/` | Their values remain separate; no cross-source numeric comparison. |

Blockers carried forward:

1. **M3 mineral retrieval**: a bounded granule must be read and registered before
   any `detected`/`not_detected_under_valid_observation` state; resolve
   per-pixel geolocation, thermal correction and polar illumination.
2. **M3 resolution**: the L2 REFIMG label does not state a per-product pixel size;
   use official instrument/dataset documentation or a measured native grid, not
   an inferred swath-width value.
3. **CRISM detection**: pin the ATBD/DP-mask definitions and validate thresholds
   on labelled spectra before promoting summary parameters from context.
4. **LROC TiO2 polar coverage**: the available 400 m/px tiles stop at 70°; do not
   extrapolate or zero-fill the polar AOI.
5. **Mars AOI status**: both Mars AOIs remain `test_aoi`; they are not production
   references.

## 8. What this evidence does not claim

- It does not claim that any mineral is present or absent at either AOI.
- It does not claim global, exhaustive or representative coverage.
- It does not convert footprint overlap into a similarity score or a combined
  six-dimension score.
- It does not treat a missing product as zero concentration.
- It does not modify `apps/api` schemas, scoring, or the shared D02 typed export.
