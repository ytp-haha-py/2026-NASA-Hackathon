# D05/D06 AOI evidence (Goal F, #170)

Owned deliverables for bounded AOI evidence covering D05 (solar illumination
geometry and ionizing-radiation source audit) and D06 (Moon/Mars regolith
support). Outputs are portable typed-v2/evidence records with explicit source,
version, spatial/temporal/depth support, QA/quality flags, uncertainty, and
score role. Missing values are represented as `no_coverage` (never zero-filled,
never proxy-filled).

See `docs/D05_D06_AOI_170.md` for scientific scope, sources, AOIs, and limits.
